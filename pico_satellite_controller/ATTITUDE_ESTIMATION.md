# 高精度姿勢角推定

## 実装概要

ICM-42688-P の加速度・角速度・温度を 1 回の 14 byte バーストで取得し、
core 1 上で 200 Hz の等周期処理を行う。カメラ転送や Wi-Fi 処理は core 0 に
分離されるため、従来の 2 Hz テレメトリ周期や撮影時間に積分精度が左右されない。

- ジャイロ: ±250 dps（131 LSB/dps）
- 加速度: ±2 g（16384 LSB/g）
- センサ内 UI フィルタ: 3 次、約 24 Hz
- ソフトウェア: 3 点中央値 + 20 Hz 一次 LPF
- 起動時: 2 秒間、400 点の Welford 平均・分散による静止バイアス校正
- 運用時: 0.5 秒以上の静止を検出してバイアスを低速追従し、角速度をゼロ拘束
- roll / pitch: 加速度の信頼度ゲートを備えた Mahony 型 quaternion 融合
- yaw: バイアス補償後の Z 軸角速度を倍精度・Kahan 補償付きで積分

電源投入後の 2 秒間は機体とリアクションホイールを動かさないこと。校正に失敗
した場合も動作は継続し、その後 0.5 秒以上静止すれば自動的に校正状態へ移る。
`attitude_calibrated=1` を確認してから制御を開始する。

## 積分法

既定値は `SIMPSON`。実測時刻を使う非等間隔 Simpson 則なので、OS/通信による
小さな周期揺らぎにも対応する。各パネル確定前は台形則の暫定値を返す。

TCP コマンドで積分器を切り替えられる。切替時は yaw が 0 度へリセットされる。

```text
INTEGRATION,TRAPEZOID
INTEGRATION,SIMPSON
INTEGRATION,CHEBYSHEV
INTEGRATION,GAUSS
ANGLE_RESET
```

`CHEBYSHEV` は 5 個の Chebyshev-Lobatto 節点を使う Clenshaw-Curtis 積分、
`GAUSS` は 3 点 Gauss-Legendre 積分である。センサは等間隔でしか取得できない
ため、両者は 4 点の短い時系列から補間して求積点を生成する。滑らかな運動では
高次精度になる一方、補間はノイズを増幅し得る。実機ではまず Simpson を使い、
同一の既知角度プロファイルで RMS 誤差を比較してから変更する。

## テレメトリ

既存フィールドに次を追加した。

- `roll_deg`, `pitch_deg`: 重力基準の傾斜角
- `gyro_z_angle_deg`: リセット点からの非ラップ相対 yaw
- `attitude_calibrated`: バイアス校正済みか
- `imu_samples`, `imu_rejected`: 取得品質の監視値

## 実機で精度を出すための校正

1. 電源投入時に機体を水平な剛体面へ置き、最低 2 秒静止する。
2. 既知角度の回転台で正負両方向を複数回測定し、`gyro_scale` を軸ごとに調整する。
3. 複数温度で静止バイアスを記録し、一次近似した係数を
   `gyro_temperature_slope` に設定する。
4. サーボ停止・回転中のログを比較する。振動が強ければ機械的な防振と電源の
   デカップリングを先に改善し、その後 `SOFTWARE_LPF_HZ` を下げる。
5. ground truth に対し、最終角度だけでなく角度時系列の RMSE、静止 10 分間の
   ドリフト、往復運動後のゼロ復帰誤差を評価する。

## 原理上の制約

この基板の ICM-42688-P は 6 軸 IMU で磁気センサを持たない。加速度から roll と
pitch は長時間補正できるが、重力軸まわりの絶対 yaw は観測できない。そのため
`gyro_z_angle_deg` は高精度な「相対角」であり、長時間では残留バイアス分だけ
ドリフトする。絶対 yaw が必要なら、4 面フォトダイオードから得る光源方位、
カメラの既知マーカー、磁気センサ、またはロータリエンコーダのいずれかを外部
観測として融合する必要がある。
