# 模擬衛星をリアクションホイールで回転させるための物理・制御・実験・実装調査

## 1. 結論

この模擬衛星で「サーボを一定速度で回せば、機体もほぼ一定速度で回り続ける」という予想は、**外部トルクがほぼゼロの理想系では正しい**。ホイールを静止から一定速度まで加速した結果、機体は反対向きの角運動量を持ち、その後はホイールが一定速度でも慣性で回り続ける。

しかし実機は完全な孤立系ではない。ハンドスピナーの軸受摩擦、空気抵抗、糸・ケーブルのねじり、支持部のこすれ、傾きと偏心が生む揺動・軸受荷重などが機体へ外部トルクを加える。そのため、ホイールが一定速度になって内部トルクがほぼゼロになると、機体の角運動量だけが外部トルクによって減り、機体は止まる。これは角運動量保存則と矛盾しない。摩擦はここでは、機械エネルギーを熱へ変える**散逸的な非保存力**である。角運動量について重要なのは、その摩擦が機体＋ホイール系の外から加わる**外部トルク**だという点である。[^1][^2]

現在のハードウェアのままで最も実現性が高い目的は、次の順である。

1. **目標角度へ向けて止める姿勢変更**：十分に可能。ホイールを加速して機体を回し、目標へ近づいたらホイールを減速して機体を止める。IMUによる閉ループ制御が必要である。
2. **有限時間、一定角速度で回す**：可能。機体角速度をIMUで測り、摩擦を補償するようホイール速度を徐々に変える。ただしホイールの最高速度に達すると制御不能になる。
3. **無期限に一定角速度で回し続ける**：現在のリアクションホイール単独では原理上保証できない。摩擦を補償し続けるとホイールに角運動量が蓄積し、必ず速度飽和する。無期限運転には、空気へ力を出すファン、支持台へ反力を渡すモータ、磁場へ反力を渡す磁気トルカ、スラスタ等の外部トルク源、またはホイールの運動量を外部へ捨てる仕組みが必要である。NASAとESAも、リアクションホイールは有限の運動量貯蔵装置であり、飽和回避にはスラスタや磁気トルカによるデサチュレーションが必要だとしている。[^3][^4][^5]

したがって、本ミッションの「既知の相対位置にある撮影対象の画像を得る」という要求に対しては、連続回転を主目標にするより、**太陽センサ／カメラ／IMUで方向を推定し、目標方位へ有限角だけ旋回し、静止して撮影する**方式が適している。ゼミ公式仕様も、FS90Rとタイヤをリアクションホイールとして「加速・減速し、角運動量を機体と交換する」ものと定義している。[^6][^7]

## 2. 調査対象の仕様と現行実装

### 2.1 ゼミ仕様から確定できること

公式仕様では、機体は専用スタンドからハンドスピナーにつながる糸で吊り下げられ、鉛直軸まわりのヨー1自由度だけを模擬する。ミッション要求は「太陽光源と撮影対象の相対位置が分かっている状況で、対象の画像を取得する」である。ハードウェアは変更しないこと、開発中は自由回転させず、姿勢制御をSILSで作り込み、実機では機体を固定してホイールだけを動かすこと、実際の自由回転確認は「打ち上げ」時だけという運用制約も明記されている。[^6]

姿勢制御に関係する搭載要素は次のとおりである。[^7][^8]

| 要素 | 型番・接続 | 制御での役割 |
|---|---|---|
| OBC | Raspberry Pi Pico W | 制御、推定、テレメトリ、地上コマンド |
| IMU | ICM-42688、I2C0、GP20/21 | 機体ヨー角速度、相対ヨー角、傾斜の推定 |
| アクチュエータ | FS90R、PWM、GP11 | タイヤを加減速し機体へ反作用トルクを与える |
| ホイール回転検出 | LBR-127HLD→MCP3008 CH4 | タイヤのマーカー通過を検出しRPMを推定 |
| 太陽センサ | S9066-211SB×4→MCP3008 CH0–3 | 光源方向の観測候補 |
| 電源 | 単4×4、サーボはVBAT直結 | 電池電圧でサーボ特性が変動する |

MAIN回路図では、サーボコネクタの3線はPWM、VBAT、GNDであり、信号はPico WのGP11に直結する。サーボ電源は5 V LDO後段ではなく電池VBAT直結である。フォトリフレクタ出力REFはMCP3008 CH4へ、IMUはTOP基板のI2C0へ接続されている。[^9][^10] この構成にはサーボ電流センサもモータ電流制御ドライバもないため、ソフトウェアが直接指令できるのは**トルクではなくFS90Rの速度指令に相当するパルス幅**だけである。

FS90Rの一次資料によれば、指令周期に対するパルス幅範囲は700–2300 µs、停止中心は1500 µs（公差±45 µs）、デッドバンドは90 µs、無負荷回転数は4.8 Vで約110 rpm、6 Vで約130 rpm、無負荷電流はそれぞれ約100/120 mA、ストール電流は約550/650 mAとされる。[^11] ゼミサイト掲載の回路解説も、6 V時の無負荷約120 mA、ストール約650 mAを前提としている。[^7] 実際の回転数と中立は負荷、電池電圧、個体差、温度で変わるため、採用個体の実測を正とすべきである。

### 2.2 現在のコードがしていること

現行の `servo.c` は、50 Hz相当のPWMをGP11へ出し、-100〜+100を700〜2300 µsへ線形変換する。変換後のパルス幅はコマンド受信時にPWMへ直接反映され、ソフトウェアによるスルーレート制限は行わない。`speed_percent` は校正済みrpmでもトルクでもなく、単なるパルス幅の正規化値である。

現行実装の確認箇所：

- `servo.c`：PWMピン、700–2300 µs、1500 µs停止、-100〜+100からの線形変換と即時反映
- `main.c` 298行：地上コマンド値をそのまま `servo_set_speed()` へ渡す
- `icm42688.h` 7行、`main.c` 53–65行：IMUは別コアで200 Hz更新
- `icm42688.c` 32–43行：ジャイロ±250 deg/s設定、20 HzソフトウェアLPF
- `telemetry.c` 29–63行：機体角速度、積分ヨー角、roll/pitch、フォトリフレクタADCを収集

よって現在の制御は**開ループのホイール速度指令**であり、「機体を一定速度にする制御」ではない。IMUは200 Hzで更新される一方、通常テレメトリは500 ms周期（2 Hz）なので、地上局経由の制御では遅すぎる。閉ループ制御はPico内部で50–100 Hz程度で行い、テレメトリは監視に使うべきである。

また、フォトリフレクタは現在2 Hzのテレメトリ収集時に生ADC値を1回読むだけである。100 rpmでは1回転0.6秒なので、マーカーが1個なら2 Hz読み取りではパルスを容易に見逃す。ホイールrpmを制御や飽和監視に使うには、別の周期処理で少なくとも数百Hz程度にADCを読み、ヒステリシス付きエッジ検出とパルス間隔計測を行う必要がある。

## 3. 物理モデル

### 3.1 変数

鉛直ヨー軸だけを考え、次を定義する。

- `θ`：地上に対する機体角 [rad]
- `Ω = θ̇`：機体角速度 [rad/s]
- `ψ`：機体に対するホイール相対角 [rad]
- `ω = ψ̇`：機体に対するホイール相対角速度 [rad/s]
- `J_b`：ホイールの軸回転分を除く機体の、支持軸まわり慣性モーメント [kg m²]
- `J_w`：ホイール＋サーボ出力側回転部の、回転軸まわり慣性モーメント [kg m²]
- `τ_ext`：機体＋ホイール全体系へ働く外部ヨートルク [N m]

ホイールの地上に対する角速度は `Ω + ω` である。全角運動量は

```text
H = J_b Ω + J_w(Ω + ω)
  = (J_b + J_w)Ω + J_w ω
```

であり、角運動量の時間変化は外部トルクに等しい。[^1][^2]

```text
(J_b + J_w) Ω̇ + J_w ω̇ = τ_ext                 (1)
```

モータがホイールへ与えるトルクと、筐体へ返る反作用トルクは内部トルクなので、全体系の式(1)では相殺される。

### 3.2 外部トルクがゼロなら何が起きるか

初期に機体もホイールも静止し、`τ_ext = 0` なら `H = 0` が保たれ、

```text
Ω = -J_w / (J_b + J_w) · ω                       (2)
```

となる。ホイールを正方向へ加速すると機体は負方向へ加速する。ホイールが一定相対速度へ達した時点では `ω̇ = 0` なので機体加速度もゼロになるが、式(2)の角速度は残る。つまり**一定ホイール速度になった後、機体は一定角速度で惰性回転する**。

これは「一定速度のホイールが機体を押し続ける」からではない。ホイール加速時に機体へ与えた角運動量が、その後も外部トルクなしで保存されるからである。一定速度のホイールは、理想的には追加のトルクを発生しない。

機体とホイールを再び両方停止させる有限角旋回も可能である。式(2)を時間積分すると、外部トルクが無視できる間は

```text
Δθ = -J_w / (J_b + J_w) · Δψ                     (3)
```

となる。ホイールを何回転か回し、最後にホイール速度をゼロへ戻せば、機体は反対方向へ有限角だけ移動して静止できる。ホイールの角度そのものは連続回転サーボなので何回転してもよく、問題になるのは主に最大速度、加減速能力、摩擦、目標付近の制御精度である。

### 3.3 摩擦があると、なぜ機体だけ止まるのか

実機の簡略外部トルクモデルを

```text
τ_ext = -τ_c sgn(Ω) - bΩ - k_t(θ - θ_0) + τ_p(θ) + d(t)   (4)
```

と置ける。

- `τ_c`：クーロン摩擦（速度にほぼ依存しない動摩擦）
- `bΩ`：粘性摩擦・空気抵抗の低速近似
- `k_t(θ-θ_0)`：糸やケーブルのねじりによる復元トルク
- `τ_p(θ)`：傾き、偏心、支持部形状等による角度依存の周期トルク
- `d(t)`：振動、風、接触、電池移動等の外乱

ホイールが一定速度なら `ω̇ = 0` なので、式(1)は

```text
(J_b + J_w) Ω̇ = τ_ext                            (5)
```

となる。回転方向と反対の摩擦トルクにより `Ω̇` は負となり、機体は減速する。ホイールはFS90R内部の速度制御によって回り続けても、そのために使われるモータトルクは主としてホイール自身の内部摩擦を補償するだけで、外部支持摩擦で失った全体系の角運動量を復元できない。

糸のねじりが無視できなければ、機体は単に止まるだけでなく、ある角度まで回って戻り、減衰振動する。毎回ほぼ同じ角度で止まる、または逆回転するなら、軸受摩擦だけでなくねじり復元トルクを疑うべきである。毎回異なる位置で止まり、速度がほぼ直線的に落ちるならクーロン摩擦優勢、指数関数的に落ちるなら粘性摩擦優勢の可能性が高い。

### 3.4 一定機体速度を維持する条件と飽和

目標角速度を一定、すなわち `Ω̇ = 0` にしたい場合、式(1)から

```text
J_w ω̇ = τ_ext                                    (6)
```

が必要である。例えば機体が正方向へ回り、摩擦が負方向なら、ホイール速度を負方向へさらに加速し続ける必要がある。その反作用が正方向の機体トルクとなり、摩擦を相殺する。

ただしFS90Rの速度範囲は有限である。利用可能なホイール速度幅を `Δω_available`、平均抵抗トルクを `|τ_ext|` とすれば、一定速度を維持できる時間の上限は概算で

```text
t_sat ≈ J_w Δω_available / |τ_ext|                (7)
```

となる。これはリアクションホイールの「運動量容量 ÷ 外乱トルク」である。ホイールが最大速度へ達した後は同じ向きの反作用トルクを出し続けられず、機体速度は再び落ちる。宇宙機でも同じ問題をホイール飽和と呼び、別の外部アクチュエータで運動量を捨てる。[^3][^4][^5]

反対方向へホイールを戻せば飽和を解除できるが、その減速反作用は機体を望まない方向へ回す。機体をその場に保持しながらホイールだけを戻すには、支持摩擦を意図的に利用するか、別の外部トルクが必要である。静止摩擦を利用したスティック・スリップ駆動は地上装置としては構成できるが、摩擦のばらつきに強く依存し、宇宙機のリアクションホイール原理を模擬する制御ではなくなる。

## 4. 重心ずれ、傾き、摩擦の影響

### 4.1 重心が真ん中でないこと

重心が回転軸から水平距離 `e` だけずれると、支持軸まわりの慣性モーメントは平行軸の定理により

```text
J_axis = J_CM + m e²                               (8)
```

だけ増える。同じホイール角運動量でも機体角速度は小さくなる。また偏心質量は回転中に軸受へ周期的な横荷重を与え、摩擦、振れ、吊り糸の振り子運動を増やす。

ただし重要な点として、**一様重力中で回転軸が完全に鉛直、拘束が理想的で、重心の高さがヨー角で変わらないなら、重心の水平ずれだけでは鉛直軸まわりの重力トルクは生じない**。重力トルク `r × mg` は主に水平軸方向である。したがって「重心が中央でないから重力が直接ヨー回転を止める」という説明は不正確である。実物では、その水平トルクが傾き、軸受面の接触、糸の曲げ、歳差運動を介してヨー摩擦や周期トルクへ結合する。

### 4.2 機体が水平でないこと

機体の見た目が水平でないこと自体も、理想的な鉛直1自由度軸なら必ずしもヨー復元トルクを意味しない。しかし実機では次を生む。

- IMUのZ軸と実際の回転軸が一致せず、`gyro_z` が真のヨー角速度を `cos(傾斜角)` 倍で測るほか、ロール・ピッチ角速度が混入する。
- ホイール軸が鉛直ヨー軸と平行でなければ、ホイールトルクのうちヨーに効くのは概ね `τ_m cos(軸ずれ角)` だけで、残りが揺動を励起する。
- 重心が支持点の真下に来ようとする振り子運動とヨーが結合し、IMU波形に周期成分が出る。
- 軸受の片当たりや支持部のこすれが増え、摩擦トルクが方向・角度依存になる。
- 回転ホイールのアンバランスが機体振動を増やし、フォトリフレクタ距離とIMU値を変調する。

### 4.3 優先すべき機械調整

ソフトウェア制御より先に、以下を行う価値が高い。

1. 電池、基板、カメラ、サーボをすべて本番位置に搭載した状態で重心を求める。
2. 吊り点を重心の鉛直上へ合わせる。変更できない場合は許される範囲の既存部品配置で偏心を最小化する。
3. 機体を水平にし、支持軸、IMU Z軸、ホイール回転軸を可能な限り平行にする。
4. ホイールの質量偏心、タイヤの振れ、軸への取付け傾きを減らす。
5. 糸や配線が回転をねじり戻さないか確認する。電力・通信は機体内で完結し、外部ケーブルを垂らさない。
6. ハンドスピナーの軸受が軸方向荷重を受けたときにも滑らかか、部品同士の接触がないか確認する。
7. 本番周囲の風と対流を抑える。ただしゼミの黒紙 enclosure や安全条件を変更しない。

バランス取りは制御を不要にするのではなく、外乱トルクを減らして式(7)の飽和時間を延ばし、モデル再現性を高める作業である。

## 5. 目的別の実現方法と実際の動き

### 5.1 方法A：目標角度へ向けて静止する（推奨）

これは撮影ミッションに最も適する。

実際の動きは次のようになる。

1. 起動後、機体とホイールを静止してIMUバイアスを校正する。
2. 現在方位と目標方位の誤差を求める。
3. ホイールを一方向へ加速し、機体を反対方向へ加速する。
4. 機体が設定した最大旋回速度へ達したら、必要に応じて速度を維持する。
5. 制動距離に入ったらホイールを反対向きに加速、すなわち現在のホイール回転を減速して、機体を減速する。
6. 目標近傍で角度誤差と角速度を小さくし、微小なホイール加減速で摩擦や外乱を打ち消す。
7. 角度・角速度が許容範囲へ一定時間入ったらHOLDへ移り、撮影は手動で指示する。

ホイールを単に一定速度で回すのではなく、**加速・制動を対にしたrest-to-rest旋回**にする。外乱が小さければ、終了時のホイール速度を開始時付近へ戻せるので、連続速度保持より飽和しにくい。

### 5.2 方法B：有限時間の一定機体角速度

機体角速度 `Ω` をIMUで測り、`Ω_ref - Ω` が正なら機体へ正トルク、負なら負トルクを出すようホイール加速度を変える。開始時にはホイール加速で機体が立ち上がり、定常時には摩擦を補償するためホイール速度が一定傾きで変化する。ホイール速度が上限に近づくほど残り運転時間が減る。

実際の速度波形は、理想的な水平線ではなく次を含む。

- FS90Rのデッドバンドと電池電圧による低周波の速度誤差
- クーロン摩擦によるスティック・スリップ
- 糸のねじりがある場合の周期的制御トルク
- 偏心・傾きによる回転角同期のリップル
- IMUフィルタ遅延による位相遅れ

制御器はこれらを抑えられるが、飽和という物理限界は消せない。制御開始前に式(7)で予定運転時間を見積もり、ホイール速度に停止・減速マージンを残す。

### 5.3 方法C：本当に連続回転させる

「機体を何分でも同じ方向へ回し続ける」こと自体が必須なら、リアクションホイールだけを使う設計目的と一致しない。次のどれかが必要である。

| 手段 | 反力を渡す相手 | 長所 | 代償 |
|---|---|---|---|
| 支持軸・スタンドをモータで直接駆動 | 地面 | 最も確実で一定速度制御が容易 | 宇宙機姿勢制御の模擬ではない |
| 小型ファン／プロペラ | 空気 | 地上で簡単に連続外部トルクを得る | ハード変更、風、騒音、宇宙では使えない |
| 接触ローラ | スタンド／壁 | 連続運転可能 | 摩耗、接触、ハード変更 |
| 磁気トルカ | 地磁気／外部コイル磁場 | 実宇宙機に近い運動量放出 | 1軸で得られるトルクが磁場方向に依存、追加回路が必要 |
| スラスタ | 噴射質量 | 実宇宙機方式 | 安全・コスト・運用上、本ゼミには不適 |

ハードウェア変更禁止を守るなら、方法Cは採用せず、方法Aまたは時間制限付き方法Bとして要件を定義すべきである。

## 6. 推奨する機能要件

ゼミサイトはミッション要求を示す一方、制御要件は各チームが導出する対象としている。[^6] 以下は調査に基づく推奨要件であり、公式に与えられた数値仕様ではない。許容誤差はミッションの画角・対象サイズ・撮影距離からチームが確定する。

### 6.1 必須機能

| ID | 推奨要件 | 検証方法 |
|---|---|---|
| FR-01 | 200 HzのIMU更新から機体ヨー角速度を取得する | 固定実機で静止ノイズ・バイアス、既知回転で符号と倍率を確認 |
| FR-02 | 起動後、機体とホイールが静止した状態でジャイロを校正し、校正完了前は姿勢制御を開始しない | テレメトリの校正フラグ確認 |
| FR-03 | 50–100 Hzの機上閉ループで、目標ヨー角またはヨー角速度を追従する | SILSおよび打ち上げログ |
| FR-04 | フォトリフレクタを高頻度に読み、ホイール回転方向・速度と有効性を推定する | 固定機体で手動／指令回転と基準動画を比較 |
| FR-05 | ホイール速度上限、PWM上限、IMU異常、ADC異常、電池低下を監視し、安全停止へ遷移する | 故障注入試験 |
| FR-06 | 制御モードをSAFE、CALIBRATION、IDLE、RATE、SLEW、HOLD、SATURATEDに分け、遷移条件を明示する | 状態遷移試験 |
| FR-07 | 角度誤差、角速度、ホイールrpm、PWM、電池電圧、飽和余裕、制御モードを記録する | ログ項目確認 |
| FR-08 | 目標到達後、所定の角度誤差・角速度範囲へ所定時間連続で入ったときHOLDへ移る。撮影は自動実行しない | SILSと打ち上げで状態遷移確認 |

### 6.2 推奨性能指標の決め方

数値は先に適当に置かず、次から導く。

- 許容角度誤差：カメラ水平画角と、対象が画面内に必要な余白から決める。
- 最大角速度：画像ブレ許容値と露光時間、IMUレンジ、停止距離から決める。
- 整定時間：打ち上げ時間と撮影枚数の運用計画から決める。
- ホールド時間：撮影・転送に必要な時間から決める。
- 飽和余裕：最悪摩擦、電池電圧、初期ホイール速度、再試行回数から決める。

初期SILS用の仮値としては、例えば最大旋回速度5–15 deg/s、撮影許可条件を角度誤差±3–5 degかつ角速度±0.5–1 deg/sが1秒継続、と置いてモデルを動かし、カメラ実験から改訂する。この数値は要求ではなく、検証を始めるための仮定である。

## 7. 制御アルゴリズム

### 7.1 推奨構造

角度制御と角速度制御を分けたカスケード構造が扱いやすい。

```text
目標角 θ_ref
   ↓ 角度誤差（最短方向へwrap）
外側P/PI制御 ──→ 目標角速度 Ω_ref（上限あり）
   ↓
内側PI/PD速度制御 ──→ 要求機体トルク τ_cmd
   ↓ τ_rw = -J_w ω̇_cmd
ホイール速度軌道／PWM変換 ──→ FS90R
   ↑                                  ↓
IMU: θ, Ω                 フォトリフレクタ: ω
```

1軸小角度では、外側を

```text
Ω_ref = sat(K_θ · wrap(θ_ref - θ), ±Ω_max)         (9)
```

内側を

```text
τ_cmd = K_p(Ω_ref - Ω) + K_i ∫(Ω_ref - Ω)dt       (10)
```

とできる。微分項を使う場合は、角度誤差の数値微分ではなく、すでにジャイロで測れる `Ω` を減衰項として使う方がノイズに強い。NASAの小型衛星資料にも、反作用ホイールの姿勢制御でPIDが一般的な構成として示されている。[^12][^13]

ただしFS90Rはトルク指令アクチュエータではないため、`τ_cmd` をそのままPWMへ線形変換できない。実用上は次の二案がある。

**案1：同定モデルを使う。** 固定機体試験から、パルス幅 `u`、電池電圧 `V`、ホイール速度 `ω` の関係を近似する。

```text
ω̇ = [K(V)(u-u_0) - ω] / T(V)                     (11)
```

必要な `ω̇_cmd = -τ_cmd/J_w` を生む `u` を逆算し、ホイール速度フィードバックで補正する。

**案2：機体角速度誤差からPWMを直接調整する。** モデル誤差に強く実装は簡単だが、FS90R内部の速度ループと外側ループが干渉し得る。低いゲインと狭いPWM範囲から始め、SILSと固定機体モデルで安定性を確認する。

### 7.2 アンチワインドアップと飽和管理

ホイール速度またはPWMが上限へ達した状態で積分項を増やし続けると、飽和解除後に大きく行き過ぎる。次を必須とする。

- PWM、ホイール目標rpm、機体目標角速度、要求トルクをそれぞれ飽和させる。
- 出力飽和中、誤差がさらに飽和を深める向きなら積分を停止する。
- フォトリフレクタから推定したrpmで、停止に必要な速度余裕を常時確保する。
- 飽和余裕が閾値を下回ったらRATE/HOLDを中止し、SATURATEDまたは安全な減速シーケンスへ移る。
- 1500 µs固定を「必ず停止」と仮定せず、個体ごとの中立 `u_0` と温度・電圧によるずれを校正する。

### 7.3 姿勢推定上の制限

ICM-42688は3軸加速度＋3軸ジャイロの6軸IMUで、磁気センサはない。TDKの仕様上、ジャイロレンジは複数選択でき、現行コードは±250 deg/sを選ぶ。[^14] 加速度計は重力からroll/pitchを補正できるが、鉛直重力軸まわりの絶対yawは観測できない。そのため現在の `gyro_z_angle` は短時間の相対角であり、残留バイアス分だけドリフトする。

短い旋回の角度制御には利用できるが、長時間の絶対方位保持には、次のいずれかを融合する。

- 既知方向の光源と、校正した4面太陽センサ
- 既知マーカーまたは撮影対象を用いたカメラ方位推定
- 外部ロータリエンコーダ（ただしハード変更）
- 磁気センサ（ただしハード変更かつ室内磁場の校正が必要）

太陽センサ4値だけでは、光源の広がり、遮蔽、感度差、傾き、距離変化を方位から一意に分離できない場合がある。事前に角度対ADC値の校正テーブルを作り、観測可能範囲と曖昧性を試験する。

## 8. パラメータ同定と実験手順

ゼミの「開発中は機体を自由回転させない」という制約を守り、固定実機試験、SILS、打ち上げ試験を分ける。[^6]

### Phase 0：安全と機械状態

1. タイヤ、ハブ、ねじ、スペーサー、電池が脱落しないことを確認する。
2. ホイール周囲にガードまたは立入禁止範囲を設ける。
3. サーボ端子のVBAT/GND/PWMを回路図と照合する。
4. ホイールを手で回し、こすれ、偏心、フォトリフレクタとの接触がないことを確認する。
5. 電池電圧を記録し、同じ電池状態で比較する。
6. ストールさせない。FS90Rは小型でも数百mA級のストール電流を取り、発熱、電圧降下、ギヤ損傷の原因になる。[^7][^11]

### Phase 1：質量特性

1. ホイールの質量 `m_w` と主要半径を測る。
2. 薄いリング近似なら `J_w ≈ m_w r²`、一様円板近似なら `J_w ≈ 1/2 m_w r²` とし、タイヤ＋ハブ＋回転するサーボギヤを部品ごとに加算する。
3. CADの質量特性が使えるなら、材質密度と搭載電池を含めて支持軸まわり `J_b` を出す。
4. 必要精度が高ければ二線／三線振り子で慣性モーメントを実測する。NASAでもbifilar/trifilar法は剛体や宇宙機部品の慣性計測法として使われ、重心を回転軸上へ置き、副次運動を避けることが重要とされる。[^15][^16] ただしこの試験がゼミの自由回転禁止に抵触するなら、運営管理下の専用試験またはCAD推定に限定する。
5. 機体重心を2方向以上から吊り下げ線で求め、吊り軸との偏心 `e` を測る。

式(2)から、同じ100 rpmのホイールでも `J_w/J_b` が1/100なら機体は約1 rpm、1/1000なら約0.1 rpmにしかならない。したがって「サーボが回っているのに機体がほとんど動かない」場合、摩擦だけでなく慣性比が小さい可能性も定量確認する。

### Phase 2：固定機体でのFS90R・回転センサ同定

1. 電源投入後2秒以上、機体とホイールを静止しIMU校正完了を確認する。
2. PWMを1500 µs近傍から小刻みに上下し、正転開始点、逆転開始点、真の停止中心、デッドバンドを求める。
3. 例として、中立から±50、±100、±150、±250、±400 µsを試し、各点5秒以上保持する。最初から700/2300 µsへ入れない。
4. フォトリフレクタADCを500–1000 Hz程度で取得し、明暗値のヒストグラムから上側・下側閾値を決める。
5. ヒステリシス付きエッジ検出を行い、連続エッジの時間差から `rpm = 60/(PPR·Δt)` を求める。PPRは1回転あたりのマーカー数である。
6. 各PWMで定常rpm、立上り時定数、逆転時間、電池電圧を記録する。
7. 正負方向を別々にフィットする。ギヤ摩擦と中立ずれのため対称とは限らない。
8. PWM急変と現行16 µs/20 msランプの双方を試し、`u→ω` の一次遅れモデル式(11)を作る。

フォトリフレクタが回転方向を単独で測れるのは、指令方向が既知である場合に限る。1個の反射センサのパルス列だけでは幾何学的に方向を判別できないため、方向は指令符号と組み合わせるか、方向反転中は不定として扱う。

### Phase 3：支持系の摩擦・ねじり同定（打ち上げ試験）

1. ホイールを停止中心にし、機体へ小さい初期角速度を与えたコーストダウンを記録する。
2. 正負両方向、複数の初期角速度、複数の開始角度で繰り返す。
3. `θ(t), Ω(t), roll(t), pitch(t)` を50 Hz以上で記録する。2 Hzの通常テレメトリだけでは不十分なので、機上バッファまたは高頻度ログを使う。
4. `J_total Ω̇` を計算し、式(4)へ最小二乗フィットする。
5. 速度ゼロ近傍で止まり続ける領域から静止摩擦上限 `τ_s` を推定する。
6. 同じ角度へ戻る傾向があれば `k_t`、角度に同期する速度リップルがあれば `τ_p(θ)`、roll/pitchと同期すれば傾斜結合を疑う。
7. 自由減衰波形が振動するなら、振動周期 `T` から概算 `k_t ≈ 4π²J_total/T²` を得る。

### Phase 4：SILS

SILSモデルへ最低限、次を入れる。

- 式(1)の機体・ホイール結合
- FS90Rの正負別一次遅れ、デッドバンド、PWM飽和、速度飽和
- クーロン摩擦、粘性摩擦、静止摩擦、糸ねじり
- IMUバイアス、白色ノイズ、20 Hz LPF相当遅延、サンプリング200 Hz
- 制御周期、量子化、通信とは独立した機上状態機械
- 電池電圧ごとのサーボ特性
- パラメータの最小／代表／最大ケース

試験ケースは、少なくともゼロ誤差、小角／大角旋回、正負方向、低／高摩擦、重心ずれ、初期機体回転、初期ホイール回転、センサ欠測、ホイール飽和、低電圧を含める。平均モデルで動くことではなく、**不利なパラメータ範囲でも安全に失敗できること**を合格条件にする。

### Phase 5：段階的な打ち上げ試験

| 試験 | 指令 | 観測したいもの | 中止条件 |
|---|---|---|---|
| T1 自由減衰 | ホイール停止、微小初速 | 摩擦、ねじり、周期トルク | 大きな揺動、接触 |
| T2 微小パルス | 中立から小さなPWM偏差を短時間 | トルク符号、機体応答、慣性比 | 予想と逆符号、振動増大 |
| T3 低速レート | 低い `Ω_ref` | 内側ループ安定性 | 持続振動、rpm余裕低下 |
| T4 小角旋回 | 10–30 deg程度 | 加速・制動、整定 | オーバーシュート上限超過 |
| T5 ミッション角 | 実際の対象方向 | 撮影許可と画像取得 | 姿勢未整定、飽和予告 |
| T6 ロバスト性 | 電池・開始角・方向を変える | 再現性 | 安全閾値超過 |

各打ち上げ後、モデル予測とログを重ね、摩擦・時定数・センサ誤差を更新してから次へ進む。最初からゲインだけを実機で試行錯誤しない。

## 9. 実装設計

この節の設計は今回コードへ反映した。実装済みコマンド、状態遷移、既定値、操作手順、検証結果は `SLEW_CAPTURE_IMPLEMENTATION.md` を参照する。

### 9.1 モジュール分割

```text
wheel_sensor.c/.h
  - MCP3008 CH4 高頻度サンプリング
  - ヒステリシス、エッジ時刻、rpm、有効性、タイムアウト

reaction_wheel.c/.h
  - PWM中立・正負校正表
  - rpm目標、速度制限、加速度制限
  - ホイール飽和余裕

attitude_control.c/.h
  - 状態機械
  - 角度外側ループ、角速度内側ループ
  - アンチワインドアップ、安全判定

plant_parameters.c/.h
  - J_b, J_w, 摩擦係数、FS90Rモデル、電圧補正

control_log.c/.h
  - 高頻度リングバッファ
  - 打ち上げ後のログ取得
```

### 9.2 周期タスク例

```text
1 kHz : フォトリフレクタADC、エッジ検出
200 Hz: 既存IMU取得・姿勢推定
100 Hz: 安全監視、ホイール速度推定更新
 50 Hz: 姿勢制御、PWM指令更新
 10 Hz: 高頻度ログの要約
  2 Hz: 既存テレメトリ送信
```

50 Hzの制御周期はFS90Rの20 ms指令周期と一致する。IMUの20 Hz LPFがあるため、制御帯域はそれより十分低く、まず1–3 Hz以下の機体閉ループ帯域から設計する。最終値はSILSの位相余裕と実測応答で決める。

### 9.3 状態機械

```text
BOOT
  → CALIBRATION（機体・ホイール静止）
  → IDLE
  → SLEW（目標角へ旋回）
  → HOLD（整定・保持）
  → IDLE

任意状態 → SAFE（センサ異常、低電圧、過大角速度）
RATE/HOLD/SLEW → SATURATED（ホイール余裕不足）→ 安全減速 → IDLE/SAFE
```

SAFEでいきなり1500 µsへ飛ばすと、高速ホイールを急制動して機体へ大きな反作用を与えることがある。「PWM中立」と「システムとして安全」は同義ではない。現在のホイールrpmと機体状態を見て、許された加速度で減速する安全シーケンスが必要である。機械破損や通信喪失が迫る場合だけ即時中立を優先する。

### 9.4 擬似コード

```text
every 20 ms:
    state = read_attitude_snapshot()
    wheel = read_wheel_speed_snapshot()
    battery = read_battery()

    if sensor_fault or overspeed or undervoltage:
        mode = SAFE

    switch mode:
      CALIBRATION:
        command calibrated_neutral
        enter IDLE only when imu_calibrated and wheel_stopped

      SLEW:
        angle_error = wrap_shortest(target_angle - yaw_relative)
        rate_ref = clamp(K_angle * angle_error, -rate_max, rate_max)
        torque_cmd = rate_controller(rate_ref, gyro_z)
        wheel_accel_cmd = -torque_cmd / J_w
        pulse = wheel_model_inverse(wheel_accel_cmd, wheel.rpm, battery)
        pulse = apply_limits_and_antiwindup(pulse, wheel)
        if settled_for_required_time: mode = HOLD

      HOLD:
        rate_ref = clamp(K_angle_hold * angle_error, ...)
        run same inner loop at lower limits
        if settled: enter_hold()

      RATE:
        torque_cmd = rate_controller(target_rate, gyro_z)
        run wheel command path
        if momentum_margin_low: mode = SATURATED

      SATURATED:
        reject indefinite rate command
        execute planned safe deceleration or request new operation

      IDLE/SAFE:
        bring wheel toward zero with bounded deceleration
```

### 9.5 テレコマ／テレメトリ案

既存 `SET_VALUE` は手動同定用として残し、姿勢制御用には意味の明確なコマンドを追加する。

```text
MODE,IDLE
MODE,SLEW,<target_relative_deg>
MODE,RATE,<target_dps>,<max_duration_ms>
CONTROL_ABORT
WHEEL_CALIBRATE
ANGLE_RESET
```

最低限追加する監視値：

```text
control_mode
target_yaw_deg
target_rate_dps
angle_error_deg
body_rate_dps
wheel_rpm
wheel_rpm_valid
wheel_momentum_margin_percent
servo_pulse_us
battery_mv
controller_p/i/d_terms
saturation_flags
abort_reason
```

`ANGLE_RESET` は相対角の原点変更であり、物理方位校正ではない。撮影対象方向との対応は、打ち上げ時の既知初期姿勢、太陽センサまたはカメラ観測で別に定義する。

## 10. 診断のための観察パターン

| 観察 | もっとも疑う原因 | 確認方法 |
|---|---|---|
| ホイール加速時だけ機体が動き、その後すぐ止まる | 支持摩擦が大きい、慣性比が小さい | コーストダウン、`J_w/J_b`計算 |
| 一定角まで行って戻る | 糸・配線のねじり復元トルク | 開始角を変え自由減衰、同じ平衡角へ戻るか |
| 1回転ごとに速さが変わる | 傾き、偏心、擦れ、角度依存トルク | `Ω`と`θ`の位相プロット、roll/pitch相関 |
| 正転と逆転で応答が違う | 軸受・ギヤ・中立の非対称 | 正負PWM sweepとコーストダウン |
| サーボ動作でIMUが跳ぶ／再起動する | 振動、電源降下、GNDノイズ | VBAT、再起動理由、固定機体IMUログ |
| 1500 µsでもゆっくり回る | FS90R中立ずれ、温度・電圧変化 | 個体別中立校正 |
| フォトリフレクタ値が安定しない | 距離変動、外光、閾値不適 | 生ADCヒストグラム、遮光、ヒステリシス |
| 角速度は安定するが角度が徐々にずれる | ジャイロ残留バイアス | 絶対方向センサとの比較 |
| 制御開始後に振動が増える | ゲイン過大、LPF遅延、機械共振 | ゲイン低下、周波数応答、SILS比較 |

## 11. 定量設計のワークシート

実測値を次へ入れると、成立性を事前判定できる。

| 量 | 記号 | 実測方法 | 値 |
|---|---|---|---|
| 機体質量 | `m_b` | はかり | 未測定 |
| 支持軸–重心偏心 | `e` | 吊り線／バランス | 未測定 |
| 機体慣性 | `J_b` | CADまたは振り子 | 未測定 |
| ホイール慣性 | `J_w` | 質量・寸法または振り子 | 未測定 |
| 正負最大ホイールrpm | `rpm_min/max` | 固定機体＋フォトリフレクタ | 未測定 |
| 平均摩擦トルク | `τ_c, b` | 自由減衰 | 未測定 |
| ねじり剛性 | `k_t` | 自由振動周期 | 未測定 |
| FS90R時定数 | `T_±(V)` | PWM step | 未測定 |
| 個体中立 | `u_0(V,T)` | PWM sweep | 未測定 |

計算順は次である。

1. 最高機体惰性速度：`Ω_max,ideal ≈ J_w/(J_b+J_w) · ω_max`
2. 目標機体加速度に必要なホイール加速度：`ω̇_req ≈ -(J_b+J_w)Ω̇_ref/J_w`
3. 一定速度保持時間：式(7)
4. 静止摩擦を越える最小ホイール加速度：`|ω̇|min > τ_s/J_w`
5. 糸ねじりが許す最大保持角：ホイール最大反作用トルクと `k_t|θ-θ_0|` の比較
6. 旋回中の停止余裕：現在のホイールrpmから安全減速に必要な時間と機体停止角をSILSで予測

この表が埋まるまで、PIDゲインの細かな最適化には進まない。最重要の不確かさは制御則ではなく、`J_w/J_b`、摩擦、ねじり、FS90Rの実速度応答である。

## 12. 最終推奨

1. 要件を「無期限の一定回転」から、ミッションに直結する「目標方位への有限角旋回・整定・撮影」へ置き直す。
2. 機械バランス、軸一致、糸・配線のねじり、接触を先に改善し、外乱トルクを減らす。
3. 固定実機でFS90Rの中立、PWM–rpm、立上り、電圧依存とフォトリフレクタを同定する。
4. 打ち上げの最初を自由減衰同定に使い、摩擦・ねじりモデルを得る。
5. そのモデルを含むSILSで、角度外側ループ＋角速度内側ループ、飽和管理、故障時遷移を検証する。
6. 打ち上げでは微小パルス→低速レート→小角旋回→ミッション角の順で段階的に広げる。
7. 一定速度運転を行う場合は最大継続時間を要件に含め、ホイール運動量余裕をテレメトリ化する。
8. 本当に無期限の連続回転が必要なら、ハードウェア変更禁止との矛盾を運営と確認し、外部トルク源または直接駆動方式へ要求変更する。
